# Board sound assets

These files come from the corresponding directories in the
[Lichess `lila` repository](https://github.com/lichess-org/lila/tree/master/public/sound).
They are distributed under Lichess's open-source licensing terms. See Lichess's
[`COPYING.md`](https://github.com/lichess-org/lila/blob/master/COPYING.md) for the current
license and individual sound-set credits.

Only the move, capture, check, and atomic explosion cues used by Atomic Puzzles are included.
